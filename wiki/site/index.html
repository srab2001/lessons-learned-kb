    Lessons Learned KB¶

    Ad Hoc's human-governed, AI-curated knowledge base of project lessons learned. Every claim is traced to a source document. Only reviewer-approved pages appear here.

    What's in the KB¶

    Section Status Purpose
    Retrospectives Empty — needs content One page per project — scope, outcomes, metrics, root causes
    Recommendations Empty — needs content Quantified claims indexed by capability area and lesson type
    Incident Reviews Empty — needs content Postmortem synthesis, root-cause findings, decision drivers
    Capability Areas Empty — needs content Cross-project synthesis by service line
    Best Practices Empty — needs content Canonical practice statements with evidence chains
    Client Context Empty — needs content Client/agency working patterns and relationship history
    Anti-Patterns Empty — needs content Documented failure patterns to recognize and avoid

    This is a freshly bootstrapped KB — no source material has been synthesized yet. See the User Guide for how to contribute the first pages.

    How to read lifecycle and confidence badges¶

    Badge Meaning
    active Reviewer-approved. Ready to reuse.
    draft Not yet reviewed. Do not rely on without checking the source.
    stale Source material updated since last compile. Verify before use.
    contradicted Two sources conflict. Awaiting maintainer resolution.
    high confidence Metric present in source with clear provenance.
    medium confidence Single source, qualitative-only, or missing metadata.
    low confidence Do not rely on for decisions. Background context only.

    Sensitivity policy¶

    Only public pages are meant for broad sharing. Internal analysis and restricted content (incident feedback, sensitive client detail) are never included in anything shared outside the KB maintainer group.
